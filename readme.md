## ✨ Le principe

Un portfolio simple et rapide, sans framework : du HTML, du CSS et une pointe de JavaScript. Il présente mes projets web et renvoie vers le reste de mon univers (blog, CV, wiki, LinkedIn).

## 🛠️ Sous le capot

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

- **Mise en page** : flexbox, pour un rendu qui s'adapte aux écrans
- **Typographie** : Google Fonts
- **Icônes** : Font Awesome
- **Hébergement** : GitHub Pages, avec un nom de domaine personnalisé (fichier `CNAME`)

## 📁 Structure du projet

```
Portfolio/
├── index.html      # Page d'accueil
├── pages/          # Pages secondaires (projets…)
├── css/            # Feuilles de style
├── img/            # Images
├── CNAME           # Domaine personnalisé
└── readme.md
```

## 💻 Lancer le projet en local

Pas de build, pas de dépendances :

```bash
git clone https://github.com/Soimuen11/Portfolio.git
cd Portfolio
xdg-open index.html
```
